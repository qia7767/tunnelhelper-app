# Tunnel Helper Windows 帮助

## 程序简介
Tunnel Helper 用于管理 SSH 密钥、连接档案和 SSH 隧道。Windows 版是桌面程序，使用系统 OpenSSH 客户端连接服务器。

## 密钥管理
用户密钥位于当前用户的 ~/.ssh，程序目录密钥位于程序目录下的 ssh_keyfiles_export。打开文件位置可在资源管理器中查看目录。导出公钥 bundle 只合并公钥，不导出私钥。删除密钥前请确认已备份。

## 生成与安装密钥
生成密钥时可以设置可选的私钥密码。将公钥安装到服务器时，可使用服务器密码或已能登录服务器的密钥；私钥不应发送给服务器。安装后可使用密钥验证检查登录。

## 配置档案
档案保存服务器地址、端口、登录用户和认证方式。复制档案会创建并保存副本，包括已填的服务器密码和私钥密码。应用到连接前会先保存当前档案。档案可能包含敏感信息，请勿公开分享 profiles.json。

## 连接与退出
在连接配置中选择档案，确认本地端口和认证方式后启动；Connections 页面显示并停止已建立的隧道。最小化会隐藏到系统托盘，点击托盘图标可恢复窗口；托盘不可用时使用普通最小化。托盘菜单可选择关闭连接并退出。窗口右上角关闭仍会先停止程序管理的连接，再退出程序。

## 常见问题
密钥认证失败时，请检查服务器用户名、公钥是否已安装、私钥权限和私钥密码。端口被占用时，请检查是否有其他程序监听该端口。密码认证失败时，请检查账号和密码。日志中的 SSH 输出可用于排查问题，分享前请检查并隐藏敏感信息。
