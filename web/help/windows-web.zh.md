# Tunnel Helper Windows 网页版

## 使用与安全
本服务运行在 Windows 机器上，可从浏览器管理密钥、档案和隧道。双击启动不创建命令窗口，可在系统托盘右键打开网页、复制 Token 或关闭连接并退出；从已有终端启动时尝试连接该终端输出诊断信息。托盘不可用时程序会尝试打开备用控制台。Token 保存在程序旁的 data/app_settings.json，请勿分享该文件。
托盘的“语言”菜单可切换中文和英文，并与网页设置共享。
默认监听所有 IPv4 地址的 6789 端口。HTTP 不加密，Token 和密码可能被同网段窃听，请仅用于可信网络或通过加密通道访问。可在配置文件中将 server.listen 设为 127.0.0.1，或启动时使用 --listen 127.0.0.1 限制本机访问。

## 密钥与档案
密钥目录路径属于运行服务的 Windows 机器，不是打开浏览器的电脑。复制路径不会传送密钥文件。档案和私钥可能包含敏感信息，请勿公开分享 data 目录。复制档案会复制其中保存的密码。

## 隧道与退出
在连接配置中选择档案并启动隧道；Connections 列表由服务共享，可在其他浏览器查看。关闭浏览器不会停止服务。使用页面的关闭服务或服务窗口中的 Ctrl+C 可停止服务管理的连接并退出。Windows 虚拟机需要保持运行，睡眠时服务无法访问。

## 当前限制
此版本为实验版，不支持 Windows 反向隧道。私钥密码和服务器密码目前只支持 ASCII 字符。跨浏览器操作、账号密码和网络中断恢复仍需更多实际环境验证。Windows 防火墙规则需由用户自行检查。
